# TABELADOR

> Este repositório serve pra armazenar um código que uso para a criação de tabelas, que uso normalmente para fazer meus horários acadêmicos, pessoais e etc...

## DESCRIÇÃO
> O código foi desenvolvido pra facilitar a criação de horários personalizados.

## TECNOLOGIAS
> O código é extremamente simples. Feito em *Python*, utilizei principalmente a biblioteca Tabulate, que auxilia no print de tabelas para interfaces no terminal e a biblioteca Termcolor, pra colorir mais facilmente os horários das tabelas.

## PORT MOBILE (em planejamento)
> A ideia é levar esse conceito pra um app Android simples com widget de tela inicial, pra ver e salvar tabelas de horário sem precisar do terminal. Ainda não foi implementado — a especificação e as decisões já tomadas estão em [`docs/mobile-spec.md`](docs/mobile-spec.md).
