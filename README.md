# TABELADOR

> Este repositório serve pra armazenar um código que uso para a criação de tabelas, que uso normalmente para fazer meus horários acadêmicos, pessoais e etc...

## DESCRIÇÃO
> O código foi desenvolvido pra facilitar a criação de horários personalizados.

## TECNOLOGIAS
> O código é extremamente simples. Feito em *Python*, utilizei principalmente a biblioteca Tabulate, que auxilia no print de tabelas para interfaces no terminal e a biblioteca Termcolor, pra colorir mais facilmente os horários das tabelas.

## PORT MOBILE (em desenvolvimento)
> A ideia é levar esse conceito pra um app Android moderno com widget de tela inicial, pra ver e montar tabelas de horário sem precisar do terminal. Em vez de digitar cada célula como no script, você cadastra suas disciplinas e atividades (nome, sigla, tipo, cor) e arrasta elas pra dentro da grade.
>
> Interface em Material 3 com cores dinâmicas do sistema. O projeto Flutter fica em [`mobile/`](mobile/) — por enquanto só o scaffold. A especificação completa, com modelo de dados e decisões de design, está em [`docs/mobile-spec.md`](docs/mobile-spec.md).
